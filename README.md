# Mobile App - Aplicación Híbrida

## Descripción

Mobile App es una aplicación móvil híbrida desarrollada utilizando Ionic Framework y React. El proyecto permite aplicar los conceptos de desarrollo multiplataforma utilizando tecnologías web.

## Objetivo

El objetivo del proyecto es desarrollar una aplicación híbrida que pueda ejecutarse en dispositivos móviles, utilizando Ionic y React para la interfaz de usuario y Capacitor para generar e integrar la aplicación con la plataforma Android.

## Tecnologías utilizadas

- Ionic Framework
- React
- TypeScript
- Capacitor
- Android
- Node.js
